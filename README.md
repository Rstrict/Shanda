# 山大 844 简答题练习册

面向山东大学 844 机械原理与机械设计复习的 React 练习组件。题库将《山大简答题手册（VIP + SVIP 论述题合编）》整理为关键词填空选择题，适合按章复习、排查易混概念和回顾错题。对于证明题、方案分析题，可以先口述完整思路，再用选项和解析核对关键词。

## 题库范围

[844.tsx](./844.tsx) 内置 247 题，包含 239 道简答题和 8 道 SVIP 论述题。内部 ID 为 q001 至 q247。页面同时保留原手册的来源题号，方便翻书核对。下表沿用手册章号。

| 章号 | 内容 |
| --- | --- |
| 0–5 | 绪论、平面机构的自由度、平面连杆机构、凸轮机构、齿轮机构、轮系 |
| 9–12 | 机械零件设计概论、联接、齿轮传动、蜗杆传动 |
| 13–16 | 带传动、链传动、轴、滑动轴承 |
| 17–19 | 滚动轴承、联轴器和离合器、一般简答题 |

14 道题带有「原书含图」标记。遇到要求按图判断或说明的题目，请结合原题册的尺寸、布置或载荷图作答。关键词练习覆盖的是提炼后的答案，部分多问题还需对照原书补全推导或举例。

## 怎么练

| 入口 | 用法 |
| --- | --- |
| 章节大厅 | 选择每轮 10、15、20 题或全部，可跳过依赖看图或作图的小问。组卷优先取到期题，其次取新题，最后取已学但尚未到期的题。 |
| 全书随机抽查 | 在全书范围抽样，也遵循跳过含图题的设置。题量选「全部」时，随机抽查取 20 题。 |
| 题库总览 | 搜索题干、还原后的完整答案、解析、SVIP 分步得分点或来源题号，叠加章节与状态筛选。展开条目可预览得分词，也可单练或批量练当前筛选结果。 |
| 到期复习 | 将当前应复习的题目打乱后组成一轮。 |
| 学习统计与错题 | 查看掌握阶段、未来七天复习量和错题记录，可集中重练错题。 |

8 道 SVIP 题采用分步自评：先按小问口述或写下答案，再展开手册得分点，勾选独立答出的项并提交。全部勾选表示答对，有遗漏会插入回炉题。题库总览也可直接查看分步答案。

普通题答题时逐空选择，选项顺序会打乱。任一空选错后会展示答案与解析，并将该题重新插入队列；如果队尾剩余题量不足，回炉题会更早出现。电脑端可按 **1–4** 或 **A–D** 选择，结果出现后按 **Enter** 或 **空格** 继续。

## 进度如何计算

新题从 S0 开始。S1 至 S7 的复习间隔依次为 **20 分钟、12 小时、1 天、2 天、4 天、7 天、15 天**。首次完成整题或到期后答对才晋一级，最高为 S7。提前重练答对保留原阶段与到期时间。开启缺图过滤后，各练习入口均保留可独立完成的文字小问，纯读图题跳过；仅完成部分小问时答对只记录本次练习。答错后回到 S1，同轮回炉答对只更新最近复习时间。总览和统计从 S6 起计入「已掌握」，S0 为未学，S1–S5 为学习中，S6、S7 均为已掌握。

进度保存在当前浏览器、当前站点的 localStorage。切换浏览器、换站点地址或清除站点数据都会影响可见的记录。换设备前先导出 JSON，在新设备打开应用后导入。导入会替换现有题目进度，建议先导出已有记录，并使用本应用生成的备份。

### 总览检索与错题复习

搜索支持跨越原挖空位置的连续短语。例如输入“引入两个约束”可以找到绪论中的运动副题。检索忽略空白、英文大小写以及常见全角／半角差异。章节和状态可以与搜索词叠加。

- **待巩固**是错题本的默认列表。答错后进入；连续两次在到期时完整答对后移出。提前练习、回炉答对和部分小问答对均不增加连续次数，再次答错会清零并重新进入。
- **历史错题**收录累计答错过的所有题，包含仍待巩固和已经巩固的题。总览与错题本采用相同口径，错题专项使用当前选中的列表。旧进度沿用备份中已有的连续答对次数。

### 导入备份时会检查什么

导入会先校验整份 JSON，包括题号、阶段、到期时间、复习时间、计数，以及随备份提供的打卡日期、模拟时间和自动切题设置。错误提示会指向首个无效字段；校验失败会保留现有进度和设置。旧备份可省略设置，缺少的累计错次、连续答对次数和最近复习时间按 0 恢复。成功导入会结束当前练习队列。

## 在本地运行

本仓库提供单文件组件，页面样式使用 Tailwind CSS，图标和统计图分别使用 lucide-react、recharts。已有配置好 Tailwind 的 React 项目可直接引入默认导出的组件。以下是从零创建预览项目的一种方式，命令以 PowerShell 为例，需要 Node.js 和 npm。

在本仓库根目录执行：

~~~powershell
npm create vite@latest shanda-preview -- --template react
cd shanda-preview
npm install
npm install lucide-react recharts react-is
npm install -D tailwindcss @tailwindcss/vite
Copy-Item ../844.tsx src/App.jsx -Force
~~~

此版本的组件使用 JSX 兼容语法，因此可以直接复制为模板的 App.jsx。将预览项目的 vite.config.js 改为：

~~~js
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
})
~~~

将预览项目的 src/index.css 内容替换为下行，保留模板 src/main.jsx 对该样式表的导入：

~~~css
@import "tailwindcss";
~~~

在预览项目目录运行 npm run dev，打开终端给出的本地地址。需要静态发布文件时执行 npm run build，产物在 dist 目录。

## 维护题库

在组件顶部的 CHAPTERS 中维护章节信息，在 RAW_QUESTIONS 中维护题目。每条记录依次保存以下八项：

~~~text
[内部 ID, 章号, 来源题号, 题干, 答案模板, 各空选项组, 解析, 原书含图标记]
~~~

- 保持已发布题目的内部 ID 稳定，浏览器用它关联历史进度。来源题号可能跨章节重复，不能代替内部 ID。
- 答案模板用 {{0}}、{{1}} 对应选项组，每组第一项为正确答案，其他项为干扰项。展示顺序由运行时打乱。
- 更新多问题时，逐项核对题干中的“判断、说明、举例、证明”等要求。若结论已写在题干，可把挖空位置放在条件、推理依据或关键步骤上。
- 修改含图标记后，可分别从章节练习和全书随机抽查检查过滤效果。修改题目内容后，可用题库总览核对预览，再用单题精练核对答案判定。
